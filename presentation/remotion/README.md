# Mission 2 presentation source

This Remotion composition renders the submission presentation in `artifacts/submission/mission2-presentation.mp4`.

## Render

```bash
npm ci
npm run lint
npx remotion render GamotaMission2 ../../artifacts/submission/mission2-presentation.mp4
```

The delivered video is 80 seconds, 1280×720, 30 fps. It is motion graphics with on-screen English text and no voiceover. It reports the verified local results and clearly marks AITC production deployment as pending; it does not claim an online endpoint.
